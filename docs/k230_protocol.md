# K230 视觉通信协议

MSPM0 只需要知道钢球相对摆杆中心的位置，因此协议保持简单、抗干扰、易调试。

## 推荐格式

```text
B:<x_mm>\n
```

示例：

```text
B:-14.2
B:0.0
B:23.5
```

含义：

- `x_mm < 0`：钢球在中心左侧。
- `x_mm = 0`：钢球位于中心。
- `x_mm > 0`：钢球在中心右侧。

## 兼容格式

```text
$BALL,<x_mm>,<y_px>,<valid>\n
```

示例：

```text
$BALL,8.0,121,1
$BALL,0,0,0
```

`valid=0` 表示没有可靠识别到钢球，主控会保持舵机回中并逐步降低动作幅度。

## 发送频率

建议 K230 每 20 ms 到 50 ms 发送一次。主控默认 200 ms 未收到有效数据就判定视觉超时。

## 舵机方向

如果钢球偏右时舵机动作后球更偏右，说明闭环方向反了，修改：

```c
#define ROBOT_BALL_SERVO_REVERSE 1
```

或改成 `0`。
