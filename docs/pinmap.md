# 接线表与引脚冲突说明

## 1. TB6612FNG 电机驱动

| TB6612 信号 | 功能 | MSPM0 引脚 | 说明 |
|---|---|---|---|
| PWMA | 左电机 PWM | PA8 | 建议 20 kHz PWM |
| AIN1 | 左电机方向 1 | PA24 | 高低组合控制正反转 |
| AIN2 | 左电机方向 2 | PA28 | 高低组合控制正反转 |
| PWMB | 右电机 PWM | PA9 | 建议 20 kHz PWM |
| BIN1 | 右电机方向 1 | PA22 | 高低组合控制正反转 |
| BIN2 | 右电机方向 2 | PA14 | 高低组合控制正反转 |
| STBY | 待机控制 | PA25 | 高电平使能 |

## 2. 四路红外循迹模块 YB-MVX01 V1.2

| 传感器 | MSPM0 引脚 | 默认权重 |
|---|---|---|
| OUT1，最左 | PB2 | -3 |
| OUT2，左中 | PB3 | -1 |
| OUT3，右中 | PB4 | +1 |
| OUT4，最右 | PB5 | +3 |

默认认为“检测到黑线”为低电平，见 `ROBOT_LINE_BLACK_LEVEL`。如果你调试时发现白底也被当成黑线，把该宏从 `0` 改为 `1`。

## 3. MPU6050

| MPU6050 | MSPM0 引脚 |
|---|---|
| SDA | PA16 |
| SCL | PA15 |
| VCC | 3.3V |
| GND | GND |

MPU6050 用于记录启动时车体初始角度，本工程默认使用陀螺仪 Z 轴积分得到相对偏航角。比赛若只要求记录初始角度，不需要复杂姿态解算。

## 4. MG996R 舵机

| 舵机线 | 连接 |
|---|---|
| 信号 | PA7，50 Hz PWM |
| VCC | 独立 5V/6V 大电流供电 |
| GND | 与 MSPM0 共地 |

MG996R 电流较大，不建议直接从主控板 5V 小电流接口供电。

## 5. K230 视觉模块

| K230 | MSPM0 |
|---|---|
| TX | PA10/RX |
| RX | PA11/TX |
| GND | GND |

串口默认 115200 8N1，协议见 [k230_protocol.md](k230_protocol.md)。

## 6. 按键

你的原图中 `PA25/PA26/PA27` 被设计成按键，但 `PA25` 已经被 TB6612 的 `STBY` 占用。默认建议：

| 功能 | 引脚 |
|---|---|
| 模式切换 | PA26 |
| 启停 | PA27 |
| 校准 | PA1 |

如果坚持使用 PA25 作为按键，必须把 TB6612 的 STBY 改接到其他空闲 GPIO，或者直接硬件上拉到高电平；否则电机驱动会被按键状态影响。
