# 比赛现场调参与测试流程

## 1. 电机方向

先架空小车，只启动电机测试。给左右轮同样正速度时，小车应该前进。

如果某一侧反转，修改：

```c
#define ROBOT_LEFT_MOTOR_REVERSE  1
#define ROBOT_RIGHT_MOTOR_REVERSE 1
```

对应侧反了就切换对应宏。

## 2. 巡线 PID

先使用低速：

```c
#define ROBOT_LINE_BASE_SPEED 280
```

调参顺序：

1. 只调 `ROBOT_LINE_KP`，让小车能明显往黑线方向修正。
2. 增加 `ROBOT_LINE_KD`，减少过弯甩动。
3. 一般巡线不需要大积分，`ROBOT_LINE_KI` 默认 0。
4. 能稳定跑完整圈后再逐步提高基础速度。

现象判断：

| 现象 | 优先调整 |
|---|---|
| 压线后反应慢 | 增大 KP |
| 左右蛇形摆动 | 增大 KD 或减小 KP |
| 弯道冲出去 | 降低基础速度，增大 KD |
| 黑线识别反了 | 切换 `ROBOT_LINE_BLACK_LEVEL` |

## 3. 舵机与滚球 PID

先让小车静止，单独运行模式二。

1. 将舵机安装到机械中位，调整 `ROBOT_SERVO_CENTER_US`。
2. 观察 K230 输出，确认钢球在右侧时 `x_mm` 为正。
3. 启动模式二，如果球越控越远，切换 `ROBOT_BALL_SERVO_REVERSE`。
4. 先调小 `ROBOT_BALL_KP`，能往目标移动后再加 `ROBOT_BALL_KD`。

## 4. 模式三联调

模式三最容易出现“车身抖动导致球控不稳”的问题。建议：

- 小车速度先降到模式一稳定速度的 60% 到 70%。
- 舵机输出限制先小一点，例如 `ROBOT_SERVO_MAX_DELTA_US 300`。
- 确认线能走稳后，再逐步提高滚球 PID。
- K230 摄像头必须固定在摆杆/凹槽上方，画面覆盖整个摆杆。

## 5. 常用安全保护

本工程已内置：

- 启动后延迟识别停车线，避免刚起步就误判终点。
- 视觉超时后舵机回中。
- 巡线丢线后按上一次误差方向低速找线。
- 电机输出限幅与斜率限制，减少起步冲击。
