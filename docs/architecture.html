02 三种模式的闭环信号链

模式一、二各自是独立闭环；模式三让两个闭环在同一 5 ms 主循环里并行运行，MPU6050 只记录角度，不参与闭环反馈。

MODE 1

红外循迹 — 差速闭环

目标 error = 0（黑线居中） 丢线策略 按最后误差方向原地/小半径搜索 结束条件 4 探头全黑 >60ms 且超过起步忽略期
MODE 2

K230 视觉滚球 — 舵机位置闭环

序列 +50mm → 稳定500ms → −50mm → 完成 丢帧保护 >200ms 无有效数据 → 清积分 + 舵机回中 方向校准 ROBOT_BALL_SERVO_REVERSE
MODE 3

巡线 + 滚球 综合 — 双闭环并行，MPU6050 仅记录

同一 5 ms tick 内先跑模式一的巡线闭环，再跑模式二闭环（去掉 ±5cm 序列，目标固定为 0），MPU6050 在 start_task() 时清零 yaw，仅用于记录相对角度，不接入任何 PID。
