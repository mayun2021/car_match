# 第1至3问控制流程

## 第1问

K230 上电后直接初始化相机和显示，持续叠加球框、毫米位置、目标和舵机脉宽。
环形赛道外的接收设备录像。第1问不占用 TI 的按键模式。

## 第2问

```text
READY
  │ K3
  ▼
LEAVE_A ──确认离开同类A标志90ms──> FOLLOW
  │ 1.2s未离开                         │
  └──────────────> FAULT               │ |偏航角|≥350°（ROBOT_Q2_FINISH_YAW_DEG）
                                          ▼
                                        BRAKE 120ms
                                          ▼
                                        DONE（时间锁存）
```

起点为 MASK=0 时记为白线；MASK=15 时记为宽黑线，仅用于起跑前的稳定性
校验。普通中心线 `MASK=6` 不是 A 标志，程序会显示 `ALIGN A MARK` 并拒绝
启动；必须把探头放在白色停车基准线或宽黑横线处，静置约 0.1 s 再按 K3。

终点判定不再依赖视觉标记：MPU6050 从 K3 按下时清零偏航角，转过
`ROBOT_Q2_FINISH_YAW_DEG`（默认 350°，且已运行满 `ROBOT_Q2_FINISH_MIN_MS`
即 8 s 以上）即视为跑完一圈，直接主动刹车。300°起进入弯道降速段
（`ROBOT_Q2_MIN_LAP_YAW_DEG`），无需再次经过 A 标志。

FOLLOW 使用已跑通的 220/KP0.24，只有“MPU在线、误差小、角速度低”的直线
升到245。弯道保持220。丢线350ms、起步异常旋转或19.8s未完成均进入故障，
不能把超时伪装成完成。

## 第3问

```text
TI K3
  │ START(seq,+50,-50)
  ▼
WAIT_ACK ──> K230 TO_POS ──稳定──> TO_NEG ──稳定──> HOLD ──> DONE
    │              K230每帧视觉+舵机闭环                     │
    └─无ACK/断链/5s超时──> FAULT                              └─继续保持-5cm
```

TI 不直接输出舵机 PWM。每次 K3 新任务先发 NEUTRAL 清除旧会话；运行和完成
保持期间每 100 ms 发送 KEEP。TI 复位或通信中断后，K230 最迟 450 ms 回中。
