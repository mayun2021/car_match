# 2026 H题第1至3问：天猛星 MSPM0G3507 + K230

这是在你们已经能正常循迹的 V2 实车程序上继续开发的比赛版。电机、四路循迹、
OLED、MPU6050 和按键引脚保持不变，只增加第2问一圈计时停车，以及第3问
K230 视觉与舵机闭环。

## 已实现

- 第1问：K230 上电即显示钢球实时画面并叠加识别框、坐标和状态；第1问不占用
  TI 按键模式。赛题要求的“环外接收、录像、回放”仍必须配合你们实际的无线
  图传发送/接收或录像设备，板载屏本身不能替代环外接收端。
- 第2问：在 A 点按 K3，顺时针方向由小车摆放朝向决定；驶离 A 后循迹一圈，
  返回同类 A 标志时主动刹车，OLED 在实际停车后锁存总时间并显示到 1 ms
  （控制与停车判定周期为 5 ms）。
- 第3问：在小车静止时按 K3，K230 本地控制钢球
  `O → +5 cm → -5 cm`，最后继续闭环保持在 -5 cm。TI 负责按键、总计时、
  OLED、通信监督和故障显示。
- TI 只有 Q2、Q3 两个模式；Q1 图像功能上电常开。

## 按键

| 按键 | MSPM0 引脚 | 功能 |
|---|---|---|
| K2 / A27 | PA27 | 停止状态下切换 Q2 / Q3 |
| K3 / A30 | PA30 | 开始；运行中再次按下为急停 |
| K1 / A17 | PA17 | 清结果并校准 MPU；Q3 时同时命令舵机回中 |

上电默认 `Q2 READY`。完成时间一直保留到再次开始、切换模式或按 K1。Q3
动作完成后若球又跑出 ±1 cm 或通信中断，OLED 会保留原完成时间，同时显示
保持故障，避免把已经失稳误报为成功。

## 已固定的实车引脚

| 功能 | 引脚 |
|---|---|
| YB-MVX01 X1/X2/X3/X4（车体左→右） | PB2/PB3/PB4/PB5，黑线低电平 |
| TB6612 PWMA/PWMB | PA8/PA9 |
| TB6612 AIN1/AIN2 | PA24/PA28 |
| TB6612 BIN1/BIN2 | PA22/PA14 |
| TB6612 STBY | PA25 |
| OLED/MPU6050 SCL/SDA | PA15/PA16 |
| TI UART TX/RX | PA10/PA11 |

`PB2` 是单片机循迹输入，`BO2` 是 TB6612 电机功率输出，两者不是同一个信号。

TI 与 K230 必须交叉连接：

```text
TI PA10 / TX  ─────> K230 IO45 / UART2_RX
TI PA11 / RX  <───── K230 IO44 / UART2_TX
TI GND        ────── K230 GND
```

MG996R 信号只接 `K230 IO42 / PWM0`，TI PA7 必须悬空，不能和 IO42 并接。
舵机使用独立 5–6 V、至少 3 A 的稳压电源；舵机电源 GND、K230 GND 和 TI
GND 三者共地。不要从 K230 或天猛星板载 5 V 直接给 MG996R 供电。

## 第2问策略与默认参数

```text
弯道/普通基础速度       220
居中直线速度            245（仅 MPU 在线、误差小、角速度低时）
KP                      0.24
最大差速修正            140
丢线停车保护            350 ms
主动刹车                120 ms
整项超时                19.8 s
允许识别终点的最短时间   8.0 s
允许识别终点的净偏航门   300°
净偏航 300° 后接近速度  205
```

按 K3 前程序取最近 16 帧（约 80 ms）判断 A 标志；必须至少 12 帧一致：

- `MASK=0`：本圈以白色断线为 A；
- `MASK=F`：本圈以宽黑横线为 A；
- 不稳定时显示 `ALIGN A MARK`，电机不会启动。重新把车放准，等待约 0.1 s
  后再按 K3。

Q2 必须检测到 MPU6050；否则显示 `MPU NEEDED` 并拒绝启动。车辆先确认已经
驶离 A，随后只有同时满足“运行 ≥8 s、净偏航绝对值 ≥300°、重新遇到锁定的
A 标志、低角速度确认”才会进入刹车。这样不会把普通白底丢线当成完成一圈。
时间在 120 ms 主动刹车结束、PWM 归零后才锁存，因此显示的是实际停车总时间。
为避免软件 I2C 全屏刷新打断 5 ms 循迹周期，Q2 行驶时 OLED 保留起跑前画面，
停车、故障或急停后立即刷新并锁定总时间；这不影响题目计时显示要求。

## 第3问结构

舵机已经接 K230，所以 TI 不再输出舵机 PWM。K230 每帧完成：

1. 只在固定 ROI 内识别钢球；
2. 用 `-5 cm / O / +5 cm` 三点像素标定换算毫米；
3. 在 K230 本地做 PD + 小积分闭环并控制 IO42/PWM0；
4. +5 cm 稳定后转向 -5 cm，最终稳定后上报完成；
5. DONE 后继续闭环；丢球超过 700 ms 或偏差超过 10 mm 持续 500 ms 即报错。

TI 在 Q3 期间每 100 ms 给 K230 发送安全 KEEP。若 TI 被复位、串口断开或程序
失去监督，K230 最迟 450 ms 自动回中，避免旧任务继续驱动舵机。OLED 锁存的
是从 K3 按下到动作完成的 TI 本地总时间。

按 K3 启动 Q3 前，TI 要求 K230 在线、视觉有效，并且钢球已经位于 O 点 ±10 mm。
动作远端截止为 4.8 s，TI 同时严格检查从 K3 按下起不超过 5.0 s。

K230 的默认像素仅是示例。必须按
[companion_k230/README.md](companion_k230/README.md) 实测 ROI、阈值和三点
像素，并把 `CALIBRATION_CONFIRMED=True`；否则 Q3 会安全锁定并报标定故障，
不能保证题目要求的 1 cm 精度。

## 编译和烧录

TI：

1. 打开 `keil/CarMatch_MSPM0G3507.uvprojx`。
2. F7 编译；本工程已用 ArmClang 6.7 验证为 `0 Error(s), 0 Warning(s)`。
3. F8 下载 `keil/Objects/CarMatch_MSPM0G3507.axf`。
4. 也可烧录 `firmware` 中同版本 AXF/HEX。

K230：

1. 用 CanMV IDE 把 `companion_k230/config.py` 和 `main.py` 一起复制到板上。
2. 先在 IDE 运行并完成三点标定、舵机方向及识别阈值检查。
3. 再把 `main.py` 设为开机脚本。

详细步骤见 [Keil5_烧录与首次运行说明.md](Keil5_烧录与首次运行说明.md)。
