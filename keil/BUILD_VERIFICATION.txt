*** STALE NOTICE ***
Lap-finish detection changed after this build: the car now stops on
pure MPU6050 yaw angle (0 -> ROBOT_LINE_FINISH_YAW_DEG, default 350
deg) instead of the four-sensor all-black stop-line marker. The
Objects/*.axf/*.hex here and ../firmware/CarMatch_MSPM0G3507*.axf/hex
were built BEFORE this change -- rebuild (F7) in Keil5 before flashing.

*** SECOND STALE NOTICE: yaw-undercount bug fixed ***
This build also predates a fix for a real bug: the ~250ms blocking
OLED flush (bit-banged I2C) caused robot_app_tick()'s control-loop dt
clamp (>50ms -> 5ms) to also starve the gyro integration, so measured
yaw ran ~20-35% slower than real rotation -- the car needed about 1.5
physical laps before software read 350 deg. Fixed by giving the gyro
integration its own real (unclamped, only capped at
ROBOT_GYRO_MAX_DT_MS=300ms) dt, separate from the control-loop dt.
Firmware version string bumped to "V3" (see ROBOT_FIRMWARE_VERSION).
Rebuild in Keil5 -- do not flash the artifacts built under this record.

*** THIRD STALE NOTICE: MPU6050-offline lockup + lap-timer fallback ***
This build also predates two more fixes, both from a field report of
"yaw stays at 0.0 the whole lap, car never stops":
  1. robot_app_init() used to discard mpu6050_init()'s return value,
     so a failed I2C bring-up (bad wiring/address/power) left yaw_deg
     stuck at 0 forever with zero indication on the OLED. Init failure
     now sets ROBOT_STATE_ERROR (OLED shows "ERR"), START is refused
     while in that state, and CALIB retries mpu6050_init() so the
     sensor can be reconnected without a power cycle.
  2. Lap completion no longer depends solely on yaw. run_line_control()
     now finishes on yaw >= ROBOT_LINE_FINISH_YAW_DEG OR elapsed time
     >= ROBOT_LINE_LAP_TIME_MS (include/robot_config.h), whichever
     comes first -- a field-timed lap-duration fallback so a dead/stuck
     gyro can no longer cause an indefinite run.
     ROBOT_LINE_LAP_TIME_MS ships with a placeholder value; it must be
     retimed on the actual track/speed before a competition run.
Firmware version string bumped to "V4". Rebuild in Keil5 -- do not
flash the artifacts built under this record.
